# Contributing

Thank you for your interest in Gaugebox!

**Bug reports and feature requests** are very welcome — please open an Issue with:

- Qt version and platform
- a minimal QML snippet that shows the problem
- for porting issues: the Qt 5 code that behaved differently

**Pull requests are not accepted at this time.** Gaugebox is dual-licensed
(GPL-3.0-only and commercial), and every line of code must be owned by the project
to keep the commercial license possible. If you have a fix, describe it in an Issue
and it will be implemented.
